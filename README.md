# StepTracker HTML - Super Simple Build!

This is a **much simpler** version that builds easily on GitHub!

## 📱 What This App Does:

- Beautiful step tracking interface
- Manual step entry (type your steps)
- Daily goal tracking
- Progress visualization
- Distance & calories calculation
- Saves data locally

**Note:** This version requires manual step entry (doesn't auto-count steps)

## 🚀 How to Build:

### Step 1: Create New Repository

1. Go to github.com
2. Tap **"+"** → **"New repository"**
3. Name: `StepTrackerHTML`
4. Select: **Public**
5. Check: **"Add a README"**
6. Tap **"Create repository"**

### Step 2: Upload These Files

Upload ALL these files to your new repository:

**Root level:**
- `build.gradle.kts`
- `settings.gradle.kts`
- `.github/workflows/build-apk.yml` (create folders as needed)

**In `app/` folder:**
- `build.gradle.kts`

**In `app/src/main/` folder:**
- `AndroidManifest.xml`

**In `app/src/main/java/com/steptracker/html/` folder:**
- `MainActivity.java` (create all folders)

**In `app/src/main/assets/` folder:**
- `index.html`

### Step 3: Build APK

1. Go to **"Actions"** tab
2. Wait for automatic build (5 minutes)
3. Download APK from Artifacts
